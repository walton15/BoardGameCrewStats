⚙️ One-Time Setup Required

Photo uploading uses imgbb for free image hosting. A free API key is required — takes about 2 minutes to set up:

  1. Go to api.imgbb.com and create a free account
  2. Copy your API key from the dashboard
  3. Open js/photos.js and replace YOUR_IMGBB_API_KEY with your key
  4. Commit and push — done!
